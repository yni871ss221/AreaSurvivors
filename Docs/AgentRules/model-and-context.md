# Model And Context Rules

- 単純なUI追加、検索、差分確認、スクリプト小修正は軽量モデル・低推論で始める。
- 大きい設計判断、原因不明バグ、Unity Scene/Prefab移行、戦闘仕様変更だけ高推論に上げる。
- 長いスレッドで固定コンテキストが重くなったら、新規チャットへ移ることを提案する。
- 新規チャットへ移る場合は、`AGENTS.md`、未完了タスク、直近検証結果だけを引き継ぐ。Obsidianや詳細ルールは必要時だけ読む。
- 作業種別が曖昧な場合は `Tools/TokenUsage/rule-router.ps1 -Task "<依頼内容>"` で読む詳細ルールと中核ファイルを絞る。
