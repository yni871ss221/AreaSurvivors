# Model And Context Rules

- `AGENTS.md`は、常時必要なユーザー意図、自動化できない安全境界、タスク別ルーティング、安定したProject Factsだけを保持し、70行以内とする。
- 個別障害、コマンド構文、数値上限、Validator名、動的な進捗は`AGENTS.md`へ追加しない。機械的に防止できる事項はコードと自己テストへ実装し、説明を重複保存しない。
- `ctx/current.md`は60行以内とし、現在の目的、最新判断、最新検証、TODO／Blocker、現行制約だけを残す。方針変更、引き継ぎ、作業終了時は追記せず最新状態で置き換え、完了情報は破棄する。履歴はGitを正とし、currentのsnapshotを別ファイルへ保存しない。
- 長いスレッドで固定コンテキストが重くなったら新規チャットへ移り、`AGENTS.md`と`ctx/current.md`だけを通常入口とする。詳細ルールはタスク一致時だけ読む。
- タスク分類が明確な場合は`AGENTS.md`の対応表から詳細ルールを直接選ぶ。分類不能な場合だけ`rule-router.ps1`を使う。
