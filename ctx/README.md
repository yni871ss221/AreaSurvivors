# ctx 運用

`ctx` は会話履歴の全文保管場所ではなく、次の作業へ引き継ぐための圧縮状態を置くディレクトリです。

## ファイル

- `current.md`: 現在のタスク、完了事項、重要判断、変更ファイル、検証結果、TODO、次の作業。
- `archive/`: 必要な場合だけ保存する詳細な調査記録や長いログ。通常の会話へ全文を再投入しない。

## 更新ルール

1. 作業開始時に `current.md` の内容を確認する。
2. 重要な判断、検証結果、未完了事項が変わった時だけ更新する。
3. コマンド出力や会話の全文は保存せず、再現に必要な要点と参照先だけ残す。
4. 作業完了時は `TODO / Blocker` を空にするか、残件を明記する。
5. 長期的なリポジトリ規約は `AGENTS.md`、個人・セッションをまたぐ記憶は既存の外部記憶運用を優先する。

## トークン効率の原則

`ctx` の全文を毎回コンテキストへ貼り付けない。現在のタスクに必要な節だけ参照し、詳細履歴は必要時に限定して読む。
